B. What this changes about the plan
  - The two capped/bounded files are LOOP.md (patch guardrails forbid bloat)
    and LOOP_LEARNINGS.md (150-line cap). Both are governed.
  - LOOP_STATE.md and CHANGELOG.md are UNGOVERNED and grow monotonically:
    3105 tok today, after ONE run. The Run Log, the backlog, and
    [Unreleased] all only ever get longer.
  - So the token problem has two halves: a large fixed cost (LOOP.md, ~6151)
    and an unbounded growing cost (LOOP_STATE + CHANGELOG). Run #1 measured
    only the first and nearly missed the second.
  => filed as R-3 (cap/roll LOOP_STATE growth) in specs/LOOP_STATE.md
